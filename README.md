## 🎯 Project Overview

**Smart Scheduling for Students** is an AI-driven scheduling engine that crafts personalized, efficient, and balanced daily schedules. Our system is designed to:

- Mix task categories to avoid cognitive fatigue.
- Prioritize tasks based on importance and deadlines.
- Respect user preferences and availability.
- Maximize productivity while maintaining flexibility.

This repository documents our full experimentation pipeline and implementation of four different scheduling paradigms.

---

## 🧠 Algorithms Explored

We rigorously tested **4 distinct approaches** to scheduling:

1. 🔁 **Genetic Algorithm + Simulated Annealing**  
   Combines exploration and exploitation to evolve optimal weekly schedules.

2. 🧩 **Constraint Satisfaction Problem + MILP (Mixed-Integer Linear Programming)**  
   Solves scheduling as a mathematical optimization problem under defined constraints.

3. 🧠 **Reinforcement Learning**  
   Learns optimal scheduling policies via reward-based training.

4. 🧠 **Deep Learning**  
   Predicts productive schedules from past data using neural networks.

## ⚙️ Features

- ⏳ Task prioritization & urgency scoring

- 🎯 User preferences handling (e.g., morning/evening focus)
